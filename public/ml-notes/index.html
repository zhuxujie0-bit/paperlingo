01📒 今日笔记 · 2026-09-12

1 · 一个词怎么变成数字：one-hot → embedding

One-hot（稀疏向量）：词表里每个词占一个位置，词表 250 词 → 每个词是 250 维向量，自己位置为 1 其余全 0。缺点：维度 = 词表大小；任意两词之间看不出任何关系。

Text embedding（稠密向量）：学一个矩阵 W¹（50×250），每一列是一个词的 embedding。W¹ @ x（x 是 one-hot）的效果 = 挑出 W¹ 对应那一列——矩阵乘 one-hot 本质是"查表"。好处：维度小，训练后意思相近的词向量也相近（king − man + woman ≈ queen）。这就是 token embedding，LLM 输入的第一步。

one-hot 只是给词编号，embedding 才是词的低维向量表示，靠 one-hot 乘 W 查出来。

2 · softmax 与 sigmoid（一对容易忘的兄弟）

sigmoidsoftmax
干什么压一个数到 0~1压一排数到 0~1 且加起来=1
公式σ(x) = 1/(1+e⁻ˣ)softmax(zᵢ) = e^zᵢ / Σⱼ e^zⱼ
形状S 曲线，0 进 0.5 出先取指数（放大差距）再归一化
用在哪二分类 / 网络中间的"开关"多分类 / 最后一层出概率分布
例子0.93 → "93% 是垃圾邮件"[2,1,0.1] → [0.66, 0.24, 0.10]

记法：sigmoid 管"一个是非题"，softmax 管"一道多选题"；sigmoid = 两类时的 softmax。sigmoid 缺点：输入很大/很小时曲线平 → 梯度消失，深层内部多用 ReLU。

sigmoid 把乱分压成"把握有多大"；softmax 把一排分压成概率分布，LLM 选下一个词就靠它。

3 · 交叉熵、KL 散度、forward KL

交叉熵：给模型的概率预测打分的尺子。L = −log(p正确)，只看正确类别。性质：越自信地错罚得越狠（p=0.1 → L=2.3；p=0.01 → L=4.6）。

CE(p,q) 的两个主角：p = true dist（真实分布 / 标准答案，固定不变）；q = dist to be learned（模型 softmax 输出，训练在调它）。

分解：CE(p,q) = H(p) + KL(p‖q)。H(p) 是答案自身的熵（常数，改不了）；KL(p‖q) ≥ 0 衡量 q 离 p 多远 → 最小化 CE ≡ 最小化 KL ≡ 逼 q 逼近 p。

Forward vs Reverse：KL 不对称。监督学习用 forward KL(p‖q)——以答案为基准，性格 zero-avoiding"一个都不能漏"，模型摊大饼；reverse KL(q‖p) 以模型为基准，zero-forcing"宁可挑食"，抱死有把握的峰（大模型蒸馏/RLHF 常用）。

softmax 负责输出概率，cross entropy 负责评价概率；评价的本质是 forward KL——拿答案当基准看模型贴得多近。

4 · Backprop 反向传播（今天的主菜）

干什么：算出"每个参数对 loss 各背多大的锅"（锅 = 梯度 = "该参数调大 1 格，loss 会变几格"）。怎么做：链式法则从输出往回乘——总变化 = 各方向贡献之和，每环局部变化率一路乘回去。

六环链条

∂L/∂y₅ = −答案/预测          ← ① 交叉熵直接求导
∂L/∂y₄ = 预测 − 答案          ← ② 穿过 softmax（项全部消掉，彩蛋）
∂L/∂y₃ = Qᵀ · ∂L/∂y₄         ← ③ 穿线性层：乘转置
∂L/∂y₂ = ∂L/∂y₃ ⊙ σ'(y₂)     ← ④ 穿 sigmoid：乘它的导数 y(1−y)
∂L/∂y₁ = Pᵀ · ∂L/∂y₂         ← ⑤ 再穿线性层
∂L/∂W  = 责任 × 当时的输入     ← ⑥ 落到参数上，用了几次加几次

全表只有三条规律

  1. 穿矩阵层乘转置：正向乘 Q，反向乘 Qᵀ
  2. 权重梯度 = 责任 × 当时的输入：∂y/∂w = x，输入是旋钮放大倍数；共享权重用了几次加几次
  3. 穿激活函数乘其导数：sigmoid 的导数 = y(1−y)

数字版一遍走通

  • 答案 "to"，模型给 0.3 → 输出的锅 = 预测−答案 = 0.3−1 = −0.6（负号 = 该输出该变大）
  • 一路乘回去，参数 w 的锅 = −2（意思：w 调大 1 格，loss 降 2 格）
  • 更新：w新 = w旧 − η×锅 = w旧 − 0.1×(−2) = w旧 + 0.2 → 下次 "to" 的概率涨一点
  • 减号的原因：梯度指 loss 上升最快方向，减号 = 反着走 = 往下降方向挪
前向算"预测得多烂"，backprop 算"每个参数背多少锅"，梯度下降按锅调参——训练就是这三步循环。

5 · 训练完整流程（Training procedure）

每个 mini-batch（一小批数据如 32 条）走一遍：

读输入+答案 → 正向传播 → 交叉熵算 loss → 该停了吗？
→ 反向传播算梯度 → 梯度下降更新参数 → 用验证集测 loss 查过拟合
  • Epoch = 整个数据集完整过一遍；训练 = 几十上百个 epoch，每个 epoch 遍历所有 mini-batch（两层循环）
  • 过拟合：练太久把训练题背下来（连噪音一起背），换新题反而变烂
  • Early stop：训练集 loss 还在降、验证集 loss 开始升 → 停，保留泛化最好的权重
数据分批喂、循环跑很多轮；旁边放个验证集盯着，一发现开始死记硬背就喊停。

LLM = 预训练学语言 → SFT 学听指令 → DPO 学讨人喜欢。原理和课堂小网络一模一样，只是规模放大。

03🧮 数学补给站 · 梯度补习班

导数 → 偏导 → 梯度，三段补齐

导数：f(x) = x²，f'(x) = 2x。意思：x 挪一点点，f 变多少。x=3 时 f'=6：x 挪 0.01，f 大约变 0.06。就这一个概念。

偏导：f(x,y) = x² + y²，∂f/∂x = 2x（把 y 当常数，一次只拧一个旋钮）。∂ 读作 "partial"。

梯度：所有偏导排成一队 ∇f = [2x, 2y]ᵀ，指向上山最快的方向。要下山（减小 loss）就反着走：新参数 = 旧参数 − 学习率 × 梯度。

梯度管"上坡"；散度管"冒水"、旋度管"打转"——后俩是物理系的事，这门课用不上。

🎮 玩一玩：梯度下降（拖小球 / 点"走一步"，看参数怎么滚到谷底）

f(x) = x²。η 太小走得慢；η 拉到 1 以上会来回蹦甚至飞出去——这就是"学习率不能乱设"。可拖动小球换出发点。

🎮 玩一玩：sigmoid（拖滑块看原始分怎么被压进 0~1）

拖到 ±8 以外：曲线几乎平了（坡度≈0）→ 梯度消失 → backprop 传回来的锅≈0 → 参数学不动。
